Аркадные гонки в тематике такси "Taxi Extreme Racer" (version 0.1).
Гейплей:
- Игрок отправляется в рабочую смену таксиста, заказы появляются на карте ввиде маркеров, за каждого доставленного пассажира игрок получает игровую валюту и оценку;
- Оценка определяется скоростью доставки пассажира и аккуратностью вождения;
- Выбор из нескольких машин с разными характеристиками;
- Мини-игра после выполнения заказа, от результатов которой меняется награда;
- Несколько видов пассажиров с разными реакциями на действия игрока;
- Система повреждений и починки транспорта;
- Задания для игрока.
